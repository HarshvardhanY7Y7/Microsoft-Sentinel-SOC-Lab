# T1059.001 — PowerShell (Execution)

## Objective

Simulate suspicious PowerShell usage and validate that Sentinel detects and surfaces the activity for investigation.

## Simulation

Executed using Atomic Red Team's PowerShell execution test on the target Windows Server VM.

## Detection

Detected via [`kql/PowerShell.kql`](../kql/PowerShell.kql), matching on PowerShell process creation (Event ID 4688) and script block logging (Event ID 4104).

## Investigation

Evidence gathered for the resulting incident:

- Executing user
- Host
- Command line
- Parent process
- Timestamp

## Outcome

The Analytics Rule fired as expected, generating an incident with the command line and parent process visible for triage.
