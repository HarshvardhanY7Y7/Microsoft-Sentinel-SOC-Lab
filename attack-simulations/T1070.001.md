# T1070.001 — Clear Windows Event Logs (Defense Evasion)

## Objective

Simulate an attacker clearing Windows event logs and confirm Sentinel detects the evasion attempt.

## Simulation

Executed using Atomic Red Team's clear event log test on the target Windows Server VM.

## Detection

Detected via [`kql/ClearEventLogs.kql`](../kql/ClearEventLogs.kql), matching on audit log clear (Event ID 1102) and system log clear (Event ID 104) events.

## Investigation

Evidence gathered for the resulting incident:

- Security Event ID
- User
- Time
- Machine

## MITRE ATT&CK Mapping

| Field | Value |
|---|---|
| Technique | Clear Windows Event Logs |
| ID | T1070.001 |

## Outcome

The Analytics Rule fired as expected, generating an incident that flagged the log-clearing event and the account that triggered it.
