# T1053.005 — Scheduled Task (Persistence)

## Objective

Simulate a persistence mechanism via scheduled task creation and confirm Sentinel detects it.

## Simulation

Executed using Atomic Red Team's scheduled task test on the target Windows Server VM.

## Detection

Detected via [`kql/ScheduledTask.kql`](../kql/ScheduledTask.kql), matching on scheduled task creation (Event ID 4698).

## Investigation

Evidence gathered for the resulting incident:

- Task name
- Creator account
- Creation time
- Associated process
