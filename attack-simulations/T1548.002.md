# T1548.002 — UAC Bypass (Privilege Escalation)

## Objective

Simulate a UAC bypass technique and confirm Sentinel detects the resulting privilege escalation.

## Simulation

Executed using Atomic Red Team's UAC bypass test on the target Windows Server VM.

## Detection

Detected via [`kql/UACBypass.kql`](../kql/UACBypass.kql), matching on elevated process creation from parent processes commonly abused for UAC bypass.

## Investigation

Evidence gathered for the resulting incident:

- Elevated process
- Parent process
- User
- Process tree

## MITRE ATT&CK Mapping

| Field | Value |

| Technique | UAC Bypass |
| ID | T1548.002 |

## Outcome

The Analytics Rule fired as expected, generating an incident showing the elevated process and its parent-child relationship.
