# T1003.001 — LSASS Memory Access (Credential Access)

## Objective

Simulate credential dumping behaviour via LSASS memory access and confirm Sentinel detects it.

## Simulation

Executed using Atomic Red Team's LSASS memory access test on the target Windows Server VM.

## Detection

Detected via [`kql/LSASS.kql`](../kql/LSASS.kql), matching on process access events (Event ID 4656/4663) targeting lsass.exe.

## Investigation

Evidence gathered for the resulting incident:

- Accessing process
- Target process
- User account
- Timestamp

## MITRE ATT&CK Mapping

| Field | Value |
|---|---|
| Technique | LSASS Memory Access |
| ID | T1003.001 |
| Tactic | Credential Access |

## Outcome

The Analytics Rule fired as expected, generating an incident showing which process attempted to access LSASS and the account context involved.
