# Lessons Learned

This project strengthened practical SOC skills by demonstrating how security telemetry flows from endpoints into Microsoft Sentinel, how custom KQL analytics rules generate actionable detections, and how simulated attacks can be investigated through structured threat hunting. It also reinforced the importance of validating detections, reducing false positives, and documenting investigations using the MITRE ATT&CK framework.
